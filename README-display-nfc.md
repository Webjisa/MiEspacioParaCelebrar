# Display físico NFC + QR — MiEspacioParaCelebrar

Soporte de sobremesa para colocar en cada local. Consta de una base y una placa frontal inclinada.

## Montaje
1. Imprimir base y placa.
2. Introducir la placa en la ranura de la base.
3. Colocar una etiqueta NFC NDEF en la cara posterior de la placa, centrada en la zona indicada.
4. Grabar en la etiqueta la URL de `tocar.html?space=UUID_DEL_ESPACIO`.
5. Colocar el QR correspondiente en la cara frontal.
6. Probar ambos sistemas con varios teléfonos.

## Diseño
El concepto visual de La Nube se incluye en `display-nfc/render-concepto-la-nube.png`. Es una referencia visual del acabado, no una fotografía técnica del STL.

## Importante
La etiqueta NFC debe contener solamente una URL. No almacenar nombres, teléfonos, correos ni otros datos personales en la etiqueta.
